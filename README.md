# FitBuddy – AI Fitness Plan Generator

FitBuddy is an AI-powered fitness planning web application.

It uses:

- FastAPI
- Jinja2
- SQLite
- SQLAlchemy
- Google Gemini
- HTML
- CSS
- Pydantic

## Features

1. Personalized 7-day workout plans
2. Nutrition and recovery tips
3. Feedback-based plan updates
4. SQLite persistence
5. Admin dashboard
6. REST API
7. Swagger documentation
8. Responsive frontend
